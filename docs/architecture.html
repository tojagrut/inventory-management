Factory Inventory Management System

Architecture overview of the demo application: a Vue 3 single-page app talking to a FastAPI service that serves in-memory mock data loaded from JSON files. There is no database and no authentication.

System architecture Tech stack Data flow API surface Gaps and notes

System architecture

Three tiers, all running locally. The browser calls the API directly at localhost:8001; CORS is open to all origins.

Tech stack

Deliberately small: three runtime dependencies on each side.

Frontend

  • Vue 3 (Composition API)
  • vue-router 4 (HTML5 history)
  • axios for HTTP
  • Vite 8 dev server, port 3000
  • Custom SVG charts, CSS Grid
  • Home-grown i18n: English / Japanese

Backend

  • Python 3.11+
  • FastAPI with Pydantic v2
  • uvicorn ASGI server, port 8001
  • uv for env and deps (pip works too)
  • Auto-generated docs at /docs

Data

  • 7 JSON files in server/data/
  • Loaded into Python lists at startup
  • Filtered with list comprehensions
  • No database, cache, or ORM

Tooling

  • pytest + FastAPI TestClient (40 tests)
  • scripts/start.sh / stop.sh
  • Claude Code: subagents, skills, hooks
  • MCP: GitHub and Playwright via npx

Data flow: changing a filter

What happens when a user picks, say, “Q3-2025” and “Tokyo” on the Dashboard.

  1. FilterBar updates shared refsuseFilters holds four module-level refs (period, location, category, status), so every view sees the same selection.
  2. The view re-fetchesThe view watches the filters, calls getCurrentFilters() (period is mapped to month) and fires parallel requests with Promise.all.
  3. api.js builds the requestValues of "all" are dropped; the rest become query params, e.g. /api/orders?warehouse=Tokyo&month=Q3-2025.
  4. FastAPI filters in memoryapply_filters narrows by warehouse, category and status; filter_by_month expands quarters via QUARTER_MAP and matches on order_date.
  5. Aggregate and validateSummary endpoints compute KPIs (inventory value, low stock, pending orders); list endpoints are validated against Pydantic response_models.
  6. Vue derives the displayRaw responses land in refs (allOrders, inventoryItems); charts, KPIs and tables are computed properties, formatted per locale and currency.

Gaps and notes

Things worth knowing before changing the code.

  • Gap The client calls /api/tasks and /api/purchase-orders, but server/main.py has no such routes, so they return 404. useAuth also ships hard-coded tasks.
  • Unused views/Backlog.vue exists but is not registered in the router or imported anywhere.
  • Inconsistent Reports.vue hard-codes http://localhost:8001 and uses axios directly instead of api.js.
  • Hard-coded Quarters are fixed to 2025 in both QUARTER_MAP and the quarterly report logic.
  • By design Inventory has no time dimension, so the period filter does not affect inventory data.
  • By design The dashboard and spending endpoints return plain dicts without response_model validation.
